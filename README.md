# ForjaTech API

API para gerenciar orçamentos para o website oficial ForjaTech.

## Versão

v0.1.0

## Descrição

Este projeto é uma API Flask para gerenciar e consultar orçamentos. Ele também inclui um módulo para envio de e-mails relacionados aos orçamentos.

## Como Executar

1.  **Crie e ative um ambiente virtual:**
    ```bash
    python -m venv venv
    source venv/bin/activate
    ```

2.  **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Execute a aplicação:**
    ```bash
    python3 flask_app.py
    ```
